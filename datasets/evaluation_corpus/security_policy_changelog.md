# Security Policy Changelog

This document tracks changes to the security policy over time.

## 2025 Changes

### 2025-Q4
- Increased minimum password length from 12 to 14 characters
- Added requirement for hardware security keys for engineering teams
- Reduced screen lock timeout from 10 minutes to 5 minutes

### 2025-Q2
- Implemented mandatory multi-factor authentication for all accounts
- Added quarterly access reviews for all internal systems
- Updated incident response process to require postmortems for P1/P2 incidents

## 2024 Changes

### 2024-Q4
- Introduced full disk encryption requirement for all company devices
- Added USB storage device restrictions
- Implemented 24-hour access revocation for role changes
