## Methodology

- **Dataset**: Evaluation corpus with 10+ documents, 50+ gold questions
- **Question taxonomy**: simple_factual, multi_hop, ambiguous, unanswerable, temporal_version, metadata_filter
- **Gold evidence**: Verbatim spans from corpus documents (strategy-agnostic)
- **Retrievers evaluated**:
  - **Dense**: Real embeddings (bge-m3) + Qdrant vector similarity
  - **Sparse**: PostgreSQL tsvector + GIN index (BM25-style ranking)
  - **Hybrid**: Dense + Sparse with Reciprocal Rank Fusion
  - **Hybrid + Reranker**: Hybrid retrieval + cross-encoder reranking (bge-reranker-v2-m3)
- **Metrics**: Recall@K, Precision@K, MRR, Hit Rate (K ∈ {5, 10, 20})
- **Evidence matching**: Containment or ≥0.7 token overlap (Phase 5 methodology)
