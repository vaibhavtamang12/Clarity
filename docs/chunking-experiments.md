## Methodology

- **Retriever held constant:** in-memory Okapi BM25 (lexical). Dense retrieval
  arrives in Phase 6+; this phase isolates the chunking variable.
- **Ground truth:** evidence-based (decision D-029). Each of the 30 questions
  carries verbatim evidence spans from the corpus; a chunk is gold iff it
  contains a span (normalized) or reaches ≥0.7 token overlap. Gold sets are
  recomputed per strategy, keeping comparisons fair across chunk shapes.
- **Pipeline fidelity:** the corpus goes through the real ingestion path
  (MarkdownParser → cleaner → structure annotator → chunker).
- **Corpus:** `chunking-corpus-v1` — 4 Markdown documents (refund policy,
  security policy, API reference, onboarding guide).
- **Not measured yet (deferred honestly):** context relevance and answer
  correctness require embeddings + LLM evaluation (Phases 21–22).
