## Methodology

- Base retriever: hybrid RRF from the Phase 8 harness (dense hash embeddings
  + pure BM25, same corpus and gold evidence spans).
- Pipeline under test: top-20 candidates → rerank → top-10 (harness scale;
  production default is top-50 → top-10 per ADR-004).
- CI reranker: deterministic hash double. This report measures **pipeline
  mechanics + latency accounting**; the real cross-encoder's quality delta
  is measured in Phase 21 on the full evaluation dataset (D-052).

## Trade-off Summary (ADR-004)

Reranking buys joint (query, chunk) scoring precision at one cross-encoder
pass per candidate. Candidate and keep counts remain experimental variables.
Failure behavior is fail-soft: a dead reranker serves the unreranked ordering
flagged as degraded — retrieval never collapses because scoring failed (D-049).
